# Reference validator and provider: resource and state findings (2026-11-20)

Four tooling reports against `packages/verifier` and `packages/provider` at `30e4668`, all
confirmed and accepted as Low under the tooling policy. None affects a contract or funds held on
chain; each could take a validator offline (missed votes, burned bonds) or waste provider compute.

| Reporter | Finding                                                                                                                                                                                                                                | Fix                                                                                                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Rama     | `/out` is a host bind mount with no disk limit (only `/tmp` is capped); outputs are read whole with `readFile`; git inputs have no size limit; a file download is buffered before its size is checked when no `content-length` is sent | `DockerRunner` measures `/work` and `/out` while the job runs and kills it past 1 GiB (the run fails, a reject vote); outputs are hashed as a stream; git fetch and checkout are killed past 1 GiB; downloads are counted while they stream (`readLimited`) |
| Instanty | Network steps have no deadline: `fetch`, the git helper and `docker pull`, all pointed at addresses the job's client chooses                                                                                                           | `AbortSignal.timeout` (120 s) on downloads, 300 s per git step, 600 s per image pull                                                                                                                                                                        |
| Instanty | The `watch` state is written with a bare `writeFile`, and a file that fails to parse is treated like a missing one: the validator silently restarts and forgets its jobs and saved specs                                               | `saveWatchState` writes to a temporary file, `fsync`s and renames; `parseWatchState` checks the shape, and the CLI stops with a clear error on an unreadable file instead of starting over                                                                  |
| Instanty | The provider's one-run-per-authorization set lives only in memory and resets on restart (the facilitator still refuses a second charge, so the loss is compute)                                                                        | Follow-up: a durable used-authorization store for `packages/provider`                                                                                                                                                                                       |

Tests: `packages/verifier/test/hardening.test.ts` (state round trip and refusals, disk
