# ARL brand assets

The ARL Network logo: three ice-blue orbits around a bright nucleus on a night-blue disc with a
polar grid and stars, and the "ARL NETWORK" wordmark set straight below the atom inside the
circle. The wordmark is Orbitron ExtraBold, outlined to vector paths so every file renders the
same without the font installed. The files are generated, not hand-drawn.

| File | Use |
| --- | --- |
| `arl-token-icon.svg`, `png/arl-token-icon-{1024,512,256,200}.png` | Token icon with the wordmark: wallets, explorers, token lists, CoinGecko / CoinMarketCap (200 px PNG, transparent corners) |
| `arl-token-icon-small.svg`, `png/arl-token-icon-small-{64,32}.png` | Token icon at 48 px and below: disc and heavy orbits, no grid or wordmark |
| `arl-app-icon.svg`, `png/arl-app-icon-512.png` | App and social avatar (X and Instagram crop it to a circle) |
| `png/arl-app-icon-180.png` | Apple touch icon: the atom badge on a square night-blue background |
| `arl-app-icon-small.svg`, `png/arl-app-icon-small-32.png` | Favicon (the website uses it as `app/icon.svg`) |
| `arl-mark-on-dark.svg`, `arl-mark-on-light.svg` | The atom alone, transparent background |
| `arl-network-logo-on-dark.svg`, `arl-network-logo-on-light.svg` | Horizontal logo: atom and wordmark |
| `arl-network-logo-stacked-on-dark.svg`, `arl-network-logo-stacked-on-light.svg` | Stacked logo |

## Colors

| Token | Value |

| Mark on light backgrounds | `#1D5F9E` |

## Rules

- Below 48 px use the `-small` variants.
- Keep clear space around the logo of at least a quarter of its width.
- Do not recolor, stretch, rotate or add effects to the logo.
- Using the logo does not imply that ARL is deployed on Base Mainnet, listed or endorsed by
  anyone.
