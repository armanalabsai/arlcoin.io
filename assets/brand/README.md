# ARL brand assets

The ARL Core mark: the Core ring with an amber orbit and a rising "A" built from network
nodes. The wordmark is Geist SemiBold ("ARL") and Geist Medium ("NETWORK"), outlined to vector
paths so every file renders the same without the font installed.

| File | Use |
| --- | --- |
| `arl-token-icon.svg`, `png/arl-token-icon-{1024,512,256,200}.png` | Token icon: wallets, explorers, token lists, CoinGecko / CoinMarketCap (200 px PNG, transparent) |
| `arl-token-icon-small.svg`, `png/arl-token-icon-small-{64,32}.png` | Token icon at 48 px and below |
| `arl-app-icon.svg`, `png/arl-app-icon-{512,180}.png` | App and social avatar; 180 px is the Apple touch icon |
| `arl-app-icon-small.svg`, `png/arl-app-icon-small-32.png` | Favicon (the website uses it as `app/icon.svg`) |
| `arl-mark-on-dark.svg`, `arl-mark-on-light.svg` | Mark alone, transparent background |
| `arl-network-logo-on-dark.svg`, `arl-network-logo-on-light.svg` | Horizontal logo |
| `arl-network-logo-stacked-on-dark.svg`, `arl-network-logo-stacked-on-light.svg` | Stacked logo |

## Colors

| Token | Value |
| --- | --- |
| Graphite (background) | `#08090B` |
| Foreground on dark | `#F2F2F0` |
| Amber (accent) | `#EEA53F` |
| Amber on light backgrounds | `#D98E22` |

## Rules

- Below 48 px use the `-small` variants: they drop the crossbar, halo and bevel, and use
  heavier strokes.
- Keep clear space around the mark of at least a quarter of its width.
- Do not recolor, stretch, rotate or add effects to the mark.
- Using the logo does not imply that ARL is deployed, listed or endorsed by anyone.
