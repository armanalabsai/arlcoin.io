# Hosting arlcoin.io on Cloudflare Pages

## Why

The Vercel team that served arlcoin.io was paused on 2026-09-28 for exceeding the Hobby plan's
fair-use limits. Its one-time 30-day courtesy unblock ran out, and since 2026-10-30 every
request to arlcoin.io, www.arlcoin.io and app.arlcoin.io answers `402 DEPLOYMENT_DISABLED`.
Search engines drop pages that keep failing, so the site moves to Cloudflare Pages: free for
static files, with no bandwidth fair-use pause.

## What is deployed

`scripts/build-cloudflare.sh` runs the same build as the Vercel deploy (`scripts/build-site.sh`:
the website and, under `/app`, the app) and lays it out for Pages:

| Vercel                           | Cloudflare Pages                                                                          |
| -------------------------------- | ----------------------------------------------------------------------------------------- |
| `apps/web/vercel.json` headers   | `_headers`, generated by `scripts/cloudflare/vercel-to-pages.mjs`                         |
| `apps/web/vercel.json` redirects | `_redirects`, generated by the same script (permanent = 308)                              |
| `apps/web/api/supply.mjs`        | Pages Function `functions/api/supply/index.js` (`scripts/cloudflare/supply-function.mjs`) |
| Shared supply code               | `apps/web/api/_supply-core.mjs`, used by both                                             |
| Vercel Web Analytics             | Left out (its script is served only by Vercel)                                            |

`_routes.json` limits the Function to `/api/*`; every other request is a static file.

`.github/workflows/deploy-cloudflare.yml` builds and deploys after CI passes on `main`, and skips
without its secrets. Checked locally with `wrangler pages dev` on 2026-10-30: pages answer 200,
`/buy` redirects to `/buy/`, `/core/team/...` redirects to `/core/`, unknown paths answer 404, the
site and the app get their own headers, and `/api/supply/` returns the on-chain figures.

## Owner steps (one time)

1. **Cloudflare account.** Sign in at https://dash.cloudflare.com (the account that already holds
   armanalabs.com's Cloudflare settings works).
2. **Pages project.** Workers & Pages → Create → Pages → "Upload assets" → name it `arlcoin`
   (or set the repository variable `CLOUDFLARE_PAGES_PROJECT` to the name you choose).
3. **API token.** My Profile → API Tokens → Create Token → "Edit Cloudflare Workers" template, or a
   custom token with Account → Cloudflare Pages → Edit.
4. **GitHub secrets.** github.com/armanalabsai/arlcoin.io → Settings → Secrets and variables →
   Actions → New repository secret: `CLOUDFLARE_API_TOKEN` (the token) and `CLOUDFLARE_ACCOUNT_ID`
   (the account ID on the dashboard's right column).
5. **First deploy.** Actions → "Deploy site (Cloudflare Pages)" → Run workflow. Check the
   `arlcoin.pages.dev` address it prints.
6. **Domain.** arlcoin.io's nameservers are Vercel's (`ns1.vercel-dns.com`, `ns2.vercel-dns.com`).
   In Cloudflare: Add a domain → `arlcoin.io` → Free plan; Cloudflare copies the existing records
   and names two nameservers. Set those nameservers at the registrar where arlcoin.io was bought.
   Then in the Pages project → Custom domains → add `arlcoin.io` and `www.arlcoin.io`.
7. **Search Console.** After the domain answers 200: Sitemaps → resubmit
   `https://arlcoin.io/sitemap.xml`, and URL Inspection → Request indexing for the home page.

## Not moved

- `app.arlcoin.io` (the testnet operator API, `scripts/deploy-app.sh`) runs as a Next.js server
  and is still on Vercel, so it stays down until it is moved or the Vercel team is restored.
  `arlcoin.io/app/` (the static app) moves with the website.
- `.github/workflows/deploy-site.yml` (Vercel) is unchanged; while the team is paused its deploy
  fails. Remove its `VERCEL_*` secrets to make it skip.
